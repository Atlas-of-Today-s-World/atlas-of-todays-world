      What you are looking at

      A shareable slice of the Atlas MVP, running entirely in this page. The real build is a Next.js app with a MapLibre globe; this demo carries the same data and design so it can be opened from a link.

      • Real data. 228 countries, 9 Atlas regions and 9 data layers imported from Natural Earth, UNDP, the World Bank, V-Dem, Transparency International and others.
      • One baked-in basemap. A shared page cannot load map tiles, so the terrain comes from a single NASA Blue Marble texture projected onto the globe. The real build streams sharper satellite tiles at every zoom.
      • No chatbot. It needs a server-side API key; search beside it is the same index the chatbot answers from.

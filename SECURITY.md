# Security

Found a vulnerability in Atlas of Today's World? Please report it privately through
[GitHub private vulnerability reporting](https://github.com/Atlas-of-Today-s-World/atlas-of-todays-world/security/advisories/new),
not as a public issue.

We aim to acknowledge reports within 5 working days. Please give us reasonable time to fix
the issue before disclosing it.

In scope: the website at https://atlas-of-todays-world.vercel.app and the code in this repository.
Out of scope: denial of service, social engineering, reports from automated scanners without a
demonstrated impact.
